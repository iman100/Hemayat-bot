# 🤖 ربات صدقه‌رس

ربات یادآوری پرداخت صدقه ماهانه / هر ۱۰ روز برای موسسه خیریه مهر یزدان.

## ✨ امکانات

- ثبت‌نام با انتخاب یادآوری ماهانه یا هر ۱۰ روز
- انتخاب روز یادآوری ماهانه (۱ تا ۲۸)
- انتخاب مبلغ از مبالغ پیشنهادی یا ورود مبلغ دلخواه
- ذخیره مبلغ برای استفاده در یادآوری‌های بعدی
- ارسال لینک پرداخت و شماره کارت به همراه یادآوری
- دکمه «پرداخت کردم» برای ثبت پرداخت
- صدقه فوری با مبلغ پیشنهادی
- پنل مدیریت: تغییر کارت، لینک، پیام سراسری، آمار
- پشتیبانی از زبان فارسی با Markdown

## 🚦 نصب و راه‌اندازی

### ۱. دریافت توکن ربات
از [@BotFather](https://t.me/BotFather) در تلگرام یک ربات بسازید و توکن را دریافت کنید.

### ۲. دریافت آیدی عددی ادمین
به [@userinfobot](https://t.me/userinfobot) پیام بدهید و آیدی عددی خود را دریافت کنید.

### ۳. نصب محلی
```bash
git clone <repo-url>
cd sadaqah-bot
pip install -r requirements.txt
```

سپس فایل `.env` بسازید:
```
BOT_TOKEN=توکن_ربات
ADMIN_ID=آیدی_عددی
```

و اجرا کنید:
```bash
python bot.py
```

### ۴. استقرار در Railway
1. مخزن GitHub بسازید و کد را push کنید
2. در [Railway](https://railway.app) یک پروژه جدید از GitHub بسازید
3. در بخش **Variables** دو متغیر را اضافه کنید:
   - `BOT_TOKEN`
   - `ADMIN_ID`
4. دیپلوی کنید. Procfile به‌طور خودکار `python bot.py` را اجرا می‌کند.

## ⚙️ پنل مدیریت

ادمین می‌تواند با دستور `/admin` به پنل دسترسی پیدا کند و:
- شماره کارت را تغییر دهد
- لینک پرداخت را تغییر دهد
- آمار کاربران را ببیند
- پیام سراسری به همه کاربران بفرستد

## 🕐 زمان یادآوری

یادآوری‌ها هر روز ساعت ۱۹:۰۰ به وقت تهران ارسال می‌شوند.
